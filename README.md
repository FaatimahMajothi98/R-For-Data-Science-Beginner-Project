# Data Analysis With R Capstone project
### By Faatimah Majothi

#### Introduction:
In this project, we explore the impact of Queen Elizabeth II's death and the subsequent mourning period on sports and betting in the United Kingdom. We analyse Google search trend data to assess national interest in popular sports and compare these trends with the stock performance of major betting companies during this period. Through our analysis, we aim to understand how this significant event influenced a familiar aspect of British life.

This project was developed as the capstone for the ["Analyze Data With R" skill path](https://www.codecademy.com/paths/analyze-data-with-r/tracks/analyze-data-with-r-capstone-project/modules/analyze-data-with-r-capstone-project/informationals/capstone-project-exploring-google-trends-data) on [Codecademy](https://www.codecademy.com/learn).  It aims to demonstrate proficiency in the **R** programming language and the integration of libraries such as `gtrendsR` within an **RStudio-based** data analysis workflow.

#### Project Goals:
- Import and perform EDA (Exploratory Data Analysis) on `gtrendsR` and stock data.
- Analyse, preprocess and combine data.
- Select suitable ML (Machine Learning) models and investigate correlation.
- Interpret results and communicate findings.
